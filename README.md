# Turan Birlik Derneği — сайт

Next.js 16 (App Router, Cache Components) + Tailwind 4. Язык сайта — турецкий.

```bash
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Где что менять

| Что | Файл |
| --- | --- |
| Контакты, IBAN, соцсети, ссылка на устав (PDF) | `lib/site.ts` |
| Ценности, направления, цели, правление, альбомы | `lib/content.ts` |
| Мероприятия (сейчас примеры) | `lib/events.ts` |
| Новости (сейчас примеры) | `lib/news.ts` |
| Цвета, шрифты, орнамент | `app/globals.css` |

Заглушки, которые нужно заменить реальными данными: адрес, телефон, WhatsApp, e-mail,
банк и IBAN, ссылки на соцсети, имена членов правления, тексты мероприятий и новостей.
Текст KVKK — общий шаблон, перед публикацией его должен проверить юрист.

Формы «Üyelik» и «İletişim» пока только проверяют поля и показывают «спасибо» —
данные никуда не сохраняются (см. `TODO` в `app/uyelik/actions.ts` и `app/iletisim/actions.ts`).
